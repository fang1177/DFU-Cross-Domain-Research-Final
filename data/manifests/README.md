# Dataset Manifests & Metadata

This directory stores reproducible records documenting dataset acquisition, image-mask pairing audits, duplicate analyses, quality checks, and train/val/test splits.

## Tracked Artifacts
- **Manifest CSV/JSON files**: Verified file lists with relative paths and cryptographic hashes.
- **Duplicate & overlap reports**: Documentation of detected duplicate images across or within datasets.
- **Data status & quality audits**: Notes on resolution distribution, mask formats, and exclusion logs.

These manifest records are deliberately tracked in version control to guarantee scientific transparency and experimental reproducibility.
